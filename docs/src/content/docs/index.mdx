## The smallest useful example

Works right now, with no account, no key and no network:

```python
import os
from glacis import Glacis

glacis = Glacis(mode="offline", signing_seed=os.urandom(32))

receipt = glacis.attest(
    service_id="claims-triage",
    operation_type="inference",
    input={"prompt": "..."},    # hashed locally, never transmitted
    output={"response": "..."}, # hashed locally, never transmitted
)

print(receipt.id)              # oatt_...
print(receipt.witness_status)  # UNVERIFIED
```

## What is transmitted

| | Leaves your environment? |
| --- | --- |
| Your prompts | No — SHA-256 hash only |
| Model outputs | No — SHA-256 hash only |
| Your provider API keys | No |
| `service_id`, `operation_type` | Yes, in witnessed mode |
| Hashes and timestamp | Yes, in witnessed mode |

In offline mode, nothing is transmitted at all. The SDK makes no network calls.

A self-signed receipt is not a cheaper witnessed receipt — it is a different
claim. Read [offline vs witnessed](/connect/offline-vs-witnessed/) before you
show one to anybody.

<Aside type="caution" title="What a receipt is not">
  A receipt is **evidence that a claim was generated**. It is not a compliance
  certificate, not an audit result, and not a statement that the model was
  right. Nothing here makes a system compliant, protected or certified.
  [What a check proves](/verify/what-a-check-proves/) draws the line precisely.
</Aside>
