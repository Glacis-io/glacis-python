**OVERT-as-Code** is the declarative policy layer for AI governance aligned to
[OVERT](/overt/). The idea: write rules under version control, validate them
before production, and keep runtime enforcement + signed records in the
[runtime product](/runtime/).

```toml
# Example shape only — Preview; not a published schema contract
[policy]
id = "example-ambient-v1"
name = "Example ambient policy"
enforcement_mode = "enforce"

[tool.defaults]
mode = "deny"

[[tool.allow]]
name = "read_patient_record"
requires_consent = true
```

## Open line vs commercial line

| Open / Preview | Commercial runtime |
| --- | --- |
| Policy language, validation, export ideas | Live enforcement on governed paths |
| Standard orientation at overt.is | Signed records, Notary, dashboard |

Declaring a policy is not proving it ran. Proof is a [runtime](/runtime/)
concern — and even then, a record is not a compliance certificate.
